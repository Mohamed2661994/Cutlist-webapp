# Cabinet Cut Optimizer

React + Vite + TypeScript workspace for a cabinet cut list optimizer with planned sheet layout and 3D preview features.

## Current Setup

- Vite 8 with React 19 and TypeScript 6
- Tailwind CSS v4 via `@tailwindcss/vite`
- `shadcn/ui` initialized and ready for component generation
- Path alias configured as `@/* -> src/*`
- VS Code task added for local development

## Scripts

- `npm run dev` starts the Vite dev server
- `npm run build` creates a production build
- `npm run lint` runs ESLint

## Status

The workspace setup is complete and the dev server task is available. The next implementation phase is the cabinet input flow, calculation engine, sheet layout, and 3D preview.
